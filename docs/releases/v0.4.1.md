Edit settings as they load and keep the previous diagnostics available while they refresh.

## Changed

- Load settings, resources, and catalogs independently so settings become editable as soon as they are ready.
- Protect unsaved drafts from stale responses, confirm before discarding a draft during reload, and retain the previous diagnostic result while refreshing.

## Fixed

- Align the three Bot resource control columns and improve wrapping for longer English labels and narrow windows.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

Open **Ducoro** in the Magpie sidebar. The page requires Magpie page-service support, `ducoro-cli`, and a running Ducoro background service.

1. Replace the previous plugin folder or update the configured package.
2. Reload the plugin to start the new version.

Existing settings and compatible management records carry forward.
