## Changed

- Reuse inventory for the immediate automatic preview. Manual and pre-save previews always fetch fresh data. Healthy full scans run every five minutes, with fast polling in degraded mode.
- Skip operation writes for verified, unchanged resources and reconcile missing resources when retrying. Validate recovery timestamps, revision hashes, retry counts, and dependency fields before backup import.

## Fixed

- Correct false connector updates caused by mismatched fingerprints and use the same instruction and subagent targets in previews and sync.
- Retain selected Bots in the plan editor across inventory refreshes and language changes.
