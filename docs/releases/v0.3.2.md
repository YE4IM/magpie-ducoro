The new settings console lets you pick target Bots, map model capabilities, and assign resources per Bot.

## Added

- Review sync status, failure reasons, affected Bots, and next steps via the unified diagnostic report or read-only CLI.
- Use inheritance or explicit empty lists for per-Bot assignments, with global sync still the default.

## Changed

- Validate scopes and resource lists before syncing, and carry forward legacy global-scope records when migrating.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

Open the **Ducoro** plugin page in Magpie. Sync uses the local `ducoro-cli`.

## Known Issues

- The console reads diagnostic snapshots through JSON import. Session loading is reported as unknown.
