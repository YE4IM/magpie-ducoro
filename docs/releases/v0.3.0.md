The first release connects Ducoro to Magpie models and syncs selected resources through the local CLI.

## Added

- Use Magpie as a model connection in Ducoro.
- Sync assigned MCP servers, skills, instructions, and explicitly selected subagents.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

In Magpie, connect the **Ducoro** Agent and select a model. Sync uses the local `ducoro-cli`.

## Known Issues

- This release supports model and resource sync. Hooks and RTK remain unsupported.
