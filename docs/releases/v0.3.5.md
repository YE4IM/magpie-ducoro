Edit account connectors in a side drawer and search the Ducoro model catalog for capability references.

## Added

- Refresh the catalog directly from Ducoro and search its entries and context limits. A failed refresh keeps the last valid catalog and references.

## Changed

- Edit account assignment, service, and allowed tools in one drawer. Closing it preserves the draft.
- Use Chinese when Magpie is set to Simplified or Traditional Chinese, and English otherwise. Language changes preserve unsaved configuration and resource names. CLI diagnostics default to English.
- Magpie generates installed-plugin descriptions from capability declarations. `magpie.summary` supplies the discovery card text.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

Open **Ducoro** in the Magpie sidebar. The page requires Magpie page-service support, `ducoro-cli`, and a running Ducoro background service.
