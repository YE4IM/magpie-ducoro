## Installation & Upgrade

In Magpie, open **Plugins → Add a plugin** and enter `magpie-ducoro@0.4.10`, or run:

```bash
magpie plugin add magpie-ducoro@0.4.10
```

If you used `npm install` to download the package, complete registration through Magpie. The `plugin add` subcommand was confirmed in Magpie’s CLI help. Registration and upgrade were not run while preparing these notes.

npm carries only the latest version. If you need this release after a newer package is published, download the source archive from this GitHub Release and register the extracted folder in Magpie.

1. Stop the previous plugin host so both versions cannot write to the same management records at once.
2. Replace the previous plugin folder or update the configured package.
3. Reload the plugin to start the new version.

Existing settings and compatible v1/v2 management records carry forward.

在 Magpie 的「插件 → 添加插件」中输入 `magpie-ducoro@0.4.10`，或运行：

```bash
magpie plugin add magpie-ducoro@0.4.10
```

通过 `npm install` 下载软件包后，请在 Magpie 中完成注册。已在 Magpie 命令行帮助中核对 `plugin add` 子命令，本次整理未实际执行注册或升级。

npm 仅保留最新版。如果更新的 npm 包已发布，需要安装这一版时，请下载本 GitHub Release 的源码压缩包，解压后在 Magpie 中注册该目录。

1. 先停止旧版插件宿主，避免两个版本同时写入管理记录。
2. 替换旧版插件目录，或更新已配置的安装包。
3. 重载插件以启动新版。

已有设置及兼容的 v1/v2 管理记录可继续使用。
