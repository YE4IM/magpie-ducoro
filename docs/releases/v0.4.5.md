Compare current and desired settings, recover drafts after reloading, and verify interrupted writes before recording ownership.

## Added

- Use the task center to retry individual failures, pause sync, or resume it. Temporary failures retry with backoff.
- Name, annotate, retain, and export management-record backups. After restoring records, preview changes and explicitly resume sync.

## Changed

- Record intent before first creation or takeover and confirm actual contents by readback before recording ownership.
- Autosave drafts and guard against simultaneous edits from multiple pages. Flag missing or ambiguous skill and instruction sources for review.
- Show where each preview value comes from and continue tracking verification in the background after a timeout.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

Open **Ducoro** in the Magpie sidebar. The page requires Magpie page-service support, `ducoro-cli`, and a running Ducoro background service.

1. Stop the previous plugin host so both versions cannot write to the same management records at once.
2. Replace the previous plugin folder or update the configured package.
3. Reload the plugin to start the new version.

Existing settings and compatible management records carry forward.
