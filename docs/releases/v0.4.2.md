Share a plan across Bots, keep individual overrides, and check incremental sync results item by item.

## Added

- See sync progress and timing, model drift, item-level verification, and selective configuration rollback.

## Changed

- Sync resources incrementally, cache skill reads, and verify results concurrently.
- Update both UI languages without losing drafts or open dialogs. The CLI supports `--lang en|zh`.

## Fixed

- Check for model drift when resuming management, expanding the target scope, or re-enabling connection sync.
- Include first-write failures and unreadable targets in instruction verification.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

Open **Ducoro** in the Magpie sidebar. The page requires Magpie page-service support, `ducoro-cli`, and a running Ducoro background service.

1. Replace the previous plugin folder or update the configured package.
2. Reload the plugin to start the new version.

Existing settings and compatible management records carry forward.
