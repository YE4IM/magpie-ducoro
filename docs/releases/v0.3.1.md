Associated Ducoro Bots follow Magpie’s default model and can use official catalog entries as capability references.

## Added

- Keep Magpie’s model selection and routing while filling Ducoro’s capability reference for supported single models and route groups. Official references such as z.ai and Kimi Coding take priority over other automatic candidates.
- Follow default model changes, repair stale Bot model IDs, and retain supported thinking levels.
- Override or disable automatic matching, watch route-group membership, and retry or recover interrupted sync.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

In Magpie, connect the **Ducoro** Agent and select a model. Sync uses the local `ducoro-cli`.

## Known Issues

- For mixed groups, unrecognized versions and known capability mismatches, diagnostics show reasons and candidates. The available reference interface cannot write a mixed group’s computed capabilities as a custom reference.
