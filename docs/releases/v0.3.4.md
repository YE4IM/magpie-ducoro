Assign resources from one settings page and check sync through live diagnostics.

## Breaking Changes

The plugin now cleans up legacy diagnostic report files on startup and no longer imports JSON snapshots. If your workflow uses those files, switch to live diagnostics.

1. Open the **Ducoro** plugin page in Magpie and use its diagnostics view for manual checks.
2. For command-line checks, use the documented read-only diagnostics CLI. It reads from the running plugin service.

## Added

- Follow the global model or pin a model per Bot. Assign Magpie library connectors, Ducoro account tools, and skills globally or per Bot where supported.
- Live diagnostics distinguish viewing time from last sync and identify stale or in-progress results.

## Fixed

- Recover the local page after a plugin reload by waiting for the old host to release its port and retrying transient reads.
- Allow the Magpie desktop page origin so the service page can load.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

Open **Ducoro** in the Magpie sidebar. The page requires Magpie page-service support, `ducoro-cli`, and a running Ducoro background service.

## 破坏性变更

插件现在会在启动时清理旧版诊断报告，并已移除 JSON 快照导入。依赖这些文件的流程需要改用实时诊断。

- 跟随全局模型或为 Bot 单独指定模型。Magpie 资源库连接器、Ducoro 账户工具和技能可按各自支持的范围分配。
