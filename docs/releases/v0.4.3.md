Review backups, restore management records, and roll back selected configuration from one page.

## Added

- Import external backups, preview restores, selectively roll back configuration, and review what local record cleanup will remove.

## Changed

- Reuse skill artifacts and concurrent reads. Incremental journals reduce full state rewrites, and retries reconcile a target’s actual state before resuming.
- Improve task cancellation, command timeout cleanup, and recovery after interrupted operations.

## Fixed

- Keep other features’ recent diagnostic results and pending issues visible during incremental sync.

## Installation & Upgrade

Download **Source code (zip)** or **Source code (tar.gz)** from this release’s **Assets**, extract it, and add that folder’s absolute path in Magpie’s plugin settings.

Open **Ducoro** in the Magpie sidebar. The page requires Magpie page-service support, `ducoro-cli`, and a running Ducoro background service.

1. Replace the previous plugin folder or update the configured package.
2. Reload the plugin to start the new version.

Existing settings and compatible management records carry forward.
