First-time setup creates a missing gateway connection, and sync previews use the same resource selection rules as apply.

## Changed

- Bound skill scans by deadline, directory depth, count, and size, and allow cancellation.
- Read back resource state after an interruption before resuming ownership, to avoid duplicates or adopting externally modified content.
- Keep drafts, selections, focus, and open dialogs when switching languages. Source downloads contain the runtime files, UI assets, essential docs, and recovery commands.

## Fixed

- Accept the CLI’s explicit JSON `null` for an absent connection and omit empty capability references when creating one. Updating can still explicitly clear old references, while empty or malformed CLI output blocks writes.
- Preview connector revocations when an export disables a connector. A skill scheduled for removal no longer appears as an update.


1. Stop the previous plugin host so both versions cannot write to the same management records at once.
2. Replace the previous plugin folder or update the configured package.
3. Reload the plugin to start the new version.

Existing settings and compatible management records carry forward.
