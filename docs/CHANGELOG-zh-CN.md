## [v0.4.11](https://github.com/YE4IM/magpie-ducoro/compare/v0.4.10...v0.4.11) - 2026-11-25

可按资源反查使用它的 Bot、对比两个 Bot，并在推广共享方案前先用一个 Bot 核验效果。

### 新增功能

- 从技能或资源库连接器反查接收它的 Bot，并查看分配来源和最近一次读回核验结果。
- 对比两个 Bot 的模型路由、资源分配、账户工具权限和核验结果，并从差异项打开对应设置。
- 让一个 Bot 试用共享方案。试用状态会跨自动同步和宿主重启保留，可核验后推广或恢复原方案。

### 行为变更

- 分配、开关、资源库条目或导出文件变化时，预览会说明资源撤销原因，并标出首次创建网关连接的操作。
- 任务中心在空闲时逐步降低轮询频率，切回页面或重试同步时立即刷新。

### 问题修复

- 兼容 Magpie 导出中以 null 表示的空资源列表，并在 MCP 导出不可读时保留托管连接器记录。
- Ducoro 规范化托管指令区块外侧空行时，保持指令预览、写入和读回核验一致。
- 读回时核对配置的网关路由，并通过一次扫描核验技能内容和文件权限。

### 维护与依赖更新

- 插件页面和诊断统一读取包版本，打包前检查安装示例中的版本号。

[发布说明](./RELEASE-NOTES.md)

## [v0.4.5](https://github.com/YE4IM/magpie-ducoro/compare/v0.4.4...v0.4.5) - 2026-11-11

可对照当前和期望设置，重载后恢复草稿，并在确认托管归属前核对中断的写入。

### 新增功能

- 在任务中心重试、暂停或恢复单项操作。临时失败会按退避间隔自动重试。
- 为备份添加名称、备注和保留标记，或导出备份。选择性回退会带上关联方案、继承关系和作用域变化。
- 支持撤销最近一次批量分配。复制使用来源 Bot 的有效配置，包括继承值。

### 行为变更

- 显示预览值来自全局设置、继承方案还是 Bot 覆盖，并列出将撤销的托管区块和文件。
- 自动保存设置和方案草稿，并在覆盖前检查多页面编辑冲突。
- 分别跟踪已保存、已写入、已读回和会话加载。超过 35 秒后转入后台核验，重新打开页面时接续。
- 创建连接器或技能前登记意图。写入中断后，读回身份和内容再确认托管归属。
- 恢复管理记录后暂停自动同步，等用户预览影响并确认继续。
- 减少重复技能准备和日志写入。超时或取消时收尾整棵命令进程树，再核对结果不确定的写入。

### 问题修复

- 选中的技能源具有相同清单名称时保留现有技能，指令导出缺失或不完整时保留现有指令。
- 按当前期望内容核验陈旧或缺失的子代理文件。资源库无效时保留已有分配。
- 技能读取、暂存和监听采用跨平台路径判断，并修复插件页面中的备份下载。
- CLI 无法安全清空连接器参数或切换传输方式时报告冲突，含逗号的连接器凭据通过引用保存。

[发布说明](./releases/v0.4.5.md)
