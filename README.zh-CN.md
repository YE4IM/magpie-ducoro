# Ducoro 0.4.3

将 Magpie 的模型、连接器、技能、指令与选定子代理同步到 Ducoro，并在插件页面按 Bot 分配资源。

## 安装

在 Magpie 插件页面添加此文件夹的绝对路径，或安装本地 `magpie-ducoro-0.4.3.tgz`。从侧边栏 **Ducoro** 打开页面，管理同步开关、Bot 资源与同步诊断。需要 Magpie 支持插件页面服务，且本机已安装 `ducoro-cli` 并启动 Ducoro 后台。

升级时替换旧版插件路径或安装包，保留已有管理记录，无需清空或迁移分配。避免同时启用两个版本。

## 0.4.3：性能与本地记录管理

### 外部备份导入与独立清空

“同步诊断”的“有效备份与恢复预览”和“配置检查点与选择性回退”均提供“导入外部文件”和“一键清空本地备份”。

- 管理记录备份选择完整的 `state.json` 快照或原有备份 JSON（v1/v2）；不能用未合并的 `.journal` 代替完整快照。
- 配置检查点选择原有检查点 JSON（version 1，含 `id`、`createdAt`、`before`、`after`）。导入会重新计算变更并生成新的本地标识，避免覆盖已有检查点。
- 文件最大 8 MiB。先校验并展示预览，确认后仅加入对应本地列表。管理记录仍需“预览恢复”；检查点仍需选择项目恢复到草稿、预览并保存。导入不会直接应用设置或写入 Bot。
- 清空前显示对应类型的文件数和大小，确认后删除该类本地备份。当前管理记录、增量日志、恢复原件、技能缓存及另一类备份保留。备份列表变化后要求重新预览。

方案按钮、备份操作区及确认弹窗统一使用有间距的按钮行，中英文长文案和窄屏自动换行。

- **共享技能版本**：相同技能名称与内容摘要复用一份已校验产物，多个获授权 Bot 不再分别复制整包。各目标的导入、权限判断及替换恢复仍独立进行。
- **增量管理记录**：细粒度变化追加到 `state.json.journal`；每 128 条记录、达到 1 MiB 或同步阶段结束时合并快照。每条增量记录包含序号与校验和，并在返回成功前完成落盘。保留最多 5 份状态快照备份。
- **按目标操作重试**：模型、指令、子代理、连接器和技能操作分别记录目标、期望摘要、依赖、执行状态与尝试次数。自动重试只调度相关功能；同版本的已完成操作跳过，失败及中断操作先核对实际状态再恢复。手动完整同步和定期同步仍核对外部变更。
- **清理本地记录**：在“同步诊断 → 本地记录管理”点击“清理本地记录”。先查看可清理数量和空间，再确认。清理已完成操作历史、历史状态备份及未使用技能缓存，并合并增量记录；保留当前归属、权限恢复数据、未完成操作和使用中的技能版本。清理期间与同步互斥，预览过期时要求重新预览。
- **自动控制累积**：已完成操作历史最多保留 500 条；不再使用且超过 7 天的技能缓存会在同步结束时回收。配置检查点沿用原有最多 20 份的策略，不属于此清理按钮的删除范围。

0.4.3 新功能现已支持中英文，包括清理入口、动态预览、确认、完成反馈与错误提示。切换语言保留已打开弹窗及原预览数据。本轮不包含产品创新功能。

升级时将 Magpie 插件路径切换到新的 0.4.3 文件夹，停止旧版本宿主后再加载新版本，避免旧版本直接写入共享管理状态。正常升级自动兼容已有 v1/v2 管理记录。需要回退时先让 0.4.3 完成同步与快照合并并停止宿主；异常中断后先由 0.4.3 恢复增量记录，再回退。不要手动删掉尚未合并的增量文件。

## 0.4.2 新增功能

本次追加增量同步、有限并发、Bot 配置方案、同步进度、漂移中心和选择性配置回退。操作说明见下方配置方案与回退章节。


- 保存后显示逐项配置核验结果，区分已核验、失败、待核实及跳过；可重新读取核验，不自动重放超时写入。模型与账户权限提供配置读回；技能、资源内容、指令和子代理尚无完整读回证据时保留为待核实。
- Bot 支持名称和 ID 搜索、状态筛选、未保存修改计数；可将模型、资源库连接器与技能分配复制到选定 Bot，确认影响范围后进入草稿。
- 诊断问题可直接跳转到对应处理区域；模型映射显示匹配来源、原因与能力差异。
- 预览补充同名资源内容变化、技能文件与指令变化摘要，无法读取时明确标为待核实。
- 管理记录保留有限数量的有效备份，提供校验、恢复预览与恢复操作。备份列表支持逐份删除，确认后移除文件并刷新列表；当前管理记录与 Bot 配置不受影响。
- 本版支持中英文界面与命令行提示，模型和资源的原始名称保持原样。

批量复制只修改草稿，仍需预览并保存；账户权限不参与批量复制。配置核验成功不代表运行中的会话已经加载。

## 0.4.0 功能概览

- **逐 Bot 预览**：点击「预览变化」查看草稿；点击「保存设置」先展示预览，再确认保存。列出全局与 Bot 层新增、撤销，以及全局资源改为按 Bot 分配时其他 Pi Agent 预计失去的插件资源。预览不会调用写入命令。
- **期望与当前对照**：Bot 卡片可展开查看 Magpie 期望模型、Ducoro 当前模型和账户工具权限。期望模型读取 Magpie 导出，不以尚未更新的 Ducoro 默认模型代替。
- **账户权限冲突处理**：对具体连接器选择「采用 Ducoro 当前权限」或「重新应用 Magpie 权限」。选择先写入页面草稿，重新预览并保存后执行。决定与读取时的权限、管理记录版本绑定，外部再次修改后旧决定失效。
- **按功能检测**：分别检查模型目录、Bot 模型命令、账户权限读取/新增/更新/撤销、Bot 连接器及技能命令。缺少能力时在对应区域提示；其他功能继续独立工作。命令存在不代表服务端权限或执行结果已验证。
- **可靠性修复**：所有 Bot 的账户撤销优先于新增；连接器错误按项隔离。管理记录无法读取、损坏或版本未知时暂停同步并保留原件。监听恢复检查使用退避，只在源文件确有变化时触发降级对账。

预览共用执行中的资源作用域、模型目标及账户权限转换逻辑。资源内容更新、同名冲突、模型能力投影、实际执行权限和运行中会话是否加载，仍在同步时核实；预览不承诺同步成功。资源范围以插件管理记录为基线，不会把用户自行安装的资源算作插件拥有。

## 界面语言

界面跟随 Magpie 语言设置：简体和繁体中文使用中文，其他及未知语言回退英文。切换语言保留草稿、搜索、勾选和打开的弹窗。命令行默认使用英文，可通过 `--lang zh` 切换中文，或使用 `--lang en` 指定英文；JSON 报告使用所选语言呈现，同时保留原始标识与结构化配置事实。Bot、模型、资源、工具名称与技术配置键保持原名。

## 管理记录恢复

在「同步诊断」中点击「重新读取管理记录」，可请求重新检查 `state.json`。默认路径为 `~/.config/magpie/ducoro-bridge/state.json`；使用 `XDG_CONFIG_HOME` 或 `DUCORO_BRIDGE_STATE_DIR` 时，以自定义目录为准。

暂时无法读取时先检查文件权限与存储状态。内容损坏时保留原件，恢复自己已有的有效备份；版本未知时使用兼容版本或兼容备份。恢复后重新读取并查看诊断。不要删除、清空或用空对象覆盖管理记录，其中包含撤销账户分配时需要恢复的原权限。

## 兼容性说明

0.4.2 的自动化验证覆盖账户权限写入、外部冲突、重新应用及撤销恢复，并验证本地 HTTP 页面服务的代理访问约束。已通过真实 CLI 确认 Ducoro 后台在线并读取账户目录，但目前无已连接的账户连接器，因此尚未完成账户权限写入和 Magpie Web 代理的实机验收。请在实际安装环境中验证账户权限写入、撤销恢复和网页代理访问；自动化通过不代表真实账户权限已验证。

## 页面与分配

- **同步设置**：控制模型连接、Bot 模型、连接器、技能、指令及子代理同步。断开连接处理、模型/连接器/技能作用域使用开关，关闭作用域开关即全局同步，开启即按 Bot 分配。
- **Bot 资源**：上方为模型、连接器、技能三个独立作用域；下方自动展示所有 Bot，名称和 ID 只读。使用刷新列表更新数据，无需手填 ID。
- **同步诊断**：每次打开或重新查看时，按需生成诊断报告；无需导入文件，不在本机保存或累积历史报告。报告分别显示查看时间和最近同步时间，同步进行中或结果过期会明确提示。配置已同步不代表运行中的会话已经加载。

模型下拉为单选，仅管理绑定当前插件连接的 Pi Agent。全局模式跟随 Magpie 默认模型；按 Bot 模式允许单独指定或跟随全局。已指定模型若不可用，保留原模型并报告待处理。页面不会自动改变其他运行方式或连接绑定。

连接器列统一呈现两种来源：

- **来自 Magpie**：分配范围限于资源库中已启用并勾选给 Ducoro 的连接器。支持全局同步，或在 Pi Agent 的 Bot 层分配。
- **来自 Ducoro**：点击每个 Bot「连接器」标题右侧的「账户配置」，在侧边抽屉中选择保持现有配备、单独指定或撤销插件分配，再勾选允许工具。先在 Ducoro 中连接服务，不把账户授权自动扩散给所有 Bot。抽屉支持 Esc、关闭按钮或「完成」退出，关闭保留页面草稿，最后点击页面「保存设置」生效。入口旁显示已选择数量；保持现有配备时，首次打开后显示读取到的配备数量。

技能从 Magpie 已分配给 Ducoro 的资源中勾选。连接器和技能均支持继承、单独选择和不分配。空列表表示本插件不分配该类资源，不屏蔽其他全局或用户自行配置的资源。为未绑定插件模型连接的 Pi Agent 单独选择资源后，该 Bot 也参与资源同步。

账户连接器的首次显式分配会记录此前策略；撤销时恢复此前策略，原本没有的条目则移除。外部手动编辑会产生冲突提示，不自动覆盖。账户连接器可用性还取决于账户配对、服务连接与 Bot 运行方式。

刷新保留未保存的选择；成功读取列表后会清理已删除 Bot 的草稿条目。读取失败不会当作空列表撤销分配。

## 上游模型能力目录

模型能力默认从当前 Ducoro 提供的官方目录自动匹配。点击「同步上游模型列表」会绕过插件的五分钟缓存，重新读取 `ducoro-cli connections catalog`，并请求重新匹配已连接模型的能力。可展开目录按模型或供应商搜索，查看参考 ID 和上下文长度。目录随 Ducoro 版本更新；按钮不会下载或升级 Ducoro，请先更新 Ducoro 再同步新模型。

上游新增模型可按完整 ID 精确匹配，无需插件为新模型系列逐项维护名称。路由组仍需确认成员为同一模型，不会将不同版本或混合模型组强行映射。手动指定优先于自动匹配，适合固定参考或禁用某条映射；移除手动映射可恢复自动匹配。编辑时可从上游目录补全参考 ID。

同步不会覆盖未保存的页面设置或手动映射。目录读取失败时保留此前有效目录和能力参考并提示重试；未取得有效目录时不会把失败当作空列表撤销配置。

## 服务与保存

插件使用本地页面服务，默认地址为 `127.0.0.1:3487`。可在 Magpie 插件选项中设置 `servicePort`。插件重载遇到旧宿主占用端口时会自动等待并重新接管；若被其他程序长期占用，请调整该选项并重新打开页面。Magpie 网页模式使用其页面服务代理。

选项通过 Magpie 正式页面消息通道保存，保存会重新加载插件宿主并执行同步。服务只监听本机，接口检查访问地址、来源和页面令牌，页面只接收必要的资源名称与状态，不接收连接凭据。

## 实时诊断

打开「同步诊断」或点击「重新查看报告」会从运行中的插件读取最新同步事实，并在内存中生成本次报告。查看报告不会重新执行同步；需要对账时先点「重试同步」，完成后再次查看。报告反映最近完成的同步，不等于持续探测服务，也不证明运行中的会话已经加载资源。

命令行同样按需读取实时服务，直接输出到终端，不自动生成文件：

```sh
node diagnostics-cli.mjs
node diagnostics-cli.mjs --json
# 自定义页面端口时：
node diagnostics-cli.mjs --port 3488
```

插件未运行时会明确提示不可连接，不会回退读取旧报告。启动时自动清理旧版生成的 `sync-status.json`、`total-status.json`、`model-capabilities.json` 及其临时文件。同步归属状态、页面令牌和恢复所需的技能备份仍会保留，以支持安全撤销。用户手动重定向或另行导出的文件由用户自行管理。

## 主要选项

| 选项 | 默认值 | 含义 |
| --- | --- | --- |
| `modelScope` | `global` | 模型全局同步或 `agents` 按 Bot 分配 |
| `botModels` | `{}` | Bot ID → 模型 ID，省略则跟随全局 |
| `mcpScope` | `global` | Magpie 来源连接器的全局或 Bot 分配 |
| `skillsScope` | `global` | 技能全局或 Bot 分配 |
| `resourceAssignments` | `{}` | Bot ID → 资源库连接器与技能名称列表；内部键为 `mcp`、`skills` |
| `accountConnectors` | `{}` | Bot ID → 账户连接器标识 → `{allow, deny}` 工具策略 |
| `servicePort` | `3487` | 页面服务端口 |
| `connectionSlug` | `magpie-ducoro` | 插件模型连接标识 |
| `modelCapabilityRefs` | `{}` | 模型到官方能力参考的手动映射 |

网关连接、模型能力参考、完整技能包、指令区块及显式子代理同步沿用原有模块。不会同步钩子或 RTK。技术配置键保持原名，界面统一使用“连接器”。

## 配置方案

“Bot 资源 → Bot 配置方案”中填写名称、可选模型 ID、资源库连接器名称、技能名称和追加指令，选择 Bot 后点击“更新方案草稿”。最后通过现有预览保存。

方案更新持续影响继承 Bot。已有单项模型/资源选择优先，可在 Bot 卡片点击“清除单项覆盖，跟随方案”。空资源列表表示不分配；账户连接器权限不参与方案。方案指令追加在插件拥有的指令区块内，撤销保留用户原有 profile。模型和资源仍受现有运行方式、目标范围和连接绑定限制。

配置键：`botPlansCatalog`、`botPlans`、`botInstructions`、`pausedModels`、`modelGuards`。方案 ID 仅接受 1–64 位字母、数字、下划线及短横线；显示名称可用中文。删除方案前先取消继承。

## 进度、漂移与回退

- 诊断页展示当前步骤、步骤耗时、CLI 调用数、合并读取数、文件读取数及最近 20 轮内存记录；重启后清空。指标覆盖这一轮的进程活动窗口，可能包含同时发生的页面读取。“重试待处理部分”按功能重新对账，保留原有读回和冲突检查。
- 漂移中心对模型展示期望、当前和上次应用值；支持采用当前模型、重新应用期望模型或暂停该 Bot 的模型管理，操作进入草稿。模型回退/重新应用携带预览时的配置摘要，写前再次读取，发现变化则保留现状。
- 指令漂移按拥有区块检查；指令核验还检查当前源导出及方案指令。技能、连接器正文和子代理没有足够完整的读回证据时明确显示待核实，暂不提供这些正文的自动冲突解决。
- 保存前创建期望配置检查点，最多保留 20 份，文件权限 0600。若宿主保存失败，可能留下未应用的检查点；回退时会检查当前值是否等于检查点的保存后值，拒绝不匹配项。
- 检查点可按配置字段及 Bot 选择回退，保留未选择项；相关方案定义和继承关系须一起选择以保持配置有效。恢复先进入草稿，再预览保存。
- 配置检查点记录模型/资源分配等插件选项，不是技能正文、完整 Bot 文件或会话快照。原管理记录备份功能独立保留。任何配置核验都不证明运行中的会话已经加载。

### 备份管理

顶部「备份管理」集中提供管理记录备份、配置检查点和底部的本地存储维护。两类备份均可点击「打开备份目录」，在本机文件管理器查看当前配置路径中的文件；目录尚不存在时会提示。管理记录恢复后仍需手动同步，检查点回退仍先进入草稿并需预览保存。

同步诊断优先展示当前结果和需要关注的问题，进度与记录、配置核验、异常排查归入可展开分组。管理记录状态与重读保留在异常排查中，并提供前往备份管理的入口。

两类备份均支持「执行备份」。有效备份保存当前管理记录（包含尚在日志中的更新），用于恢复资源归属、同步和原权限记录；配置检查点手动保存当前已保存的插件配置，不含未保存草稿。手动检查点列表显示与当前配置的差异，勾选后恢复到草稿再预览保存。二者均不备份资源正文或运行中会话。
